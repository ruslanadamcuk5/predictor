# Браузерный UI-стенд

Стенд нужен, чтобы проверять WebView-интерфейс без Android-устройства.

```powershell
python tools\ui_harness\sync_ui.py
```

Скрипт:

1. копирует `index.html`, `app.js`, `docs.js`, `style.css` из `app/src/main/assets/www`;
2. добавляет перед `app.js` подключение `mock.js`;
3. не меняет исходные assets.

Откройте `tools/ui_harness/index.html` в браузере. `mock.js` подменяет
`window.PyApp` и возвращает правдоподобные JSON-ответы для всех экранов.

## Что проверять

- нет ошибок в консоли;
- переключение 6 видов спорта в верхней панели, конструкторе и настройках;
- очередь: фильтры и карточки;
- результаты: фильтры вида/даты/поиска/статуса;
- статистика: разбивка по видам;
- конструктор: метрики/рынки/цели для каждого вида, сохранение правила;
- анализатор: скрытие «Матч»/«Партии», «Фора»/«Обе забьют»;
- настройки: TT-карточки скрыты для командных видов.

## Ограничения

`mock.js` не проверяет Python. После изменений backend обязательно запускайте
`tests/run_all.py --offline`, а на устройстве — реальную линию.

Перед проверкой всегда запускайте `sync_ui.py`: иначе стенд останется со
старой копией `app.js`.
