# Betcity Predictor — Android

Мобильное приложение, которое **само** запускает движок прогнозов из `17allsets.py`.
Python-ядро встроено в APK через Chaquopy и работает на телефоне — сервер не нужен.

Готовый файл: `Predictor-1.15.apk` (рядом с папкой проекта).

Сервер для работы не нужен. По желанию можно включить **онлайн-режим**: тогда
анализ истории и рекомендации по правилам считает сайт на alwaysdata, а при
ошибке сети приложение возвращается к локальному расчёту. Инструкция —
`server/README.md`.

## Для разработчиков и ИИ-ассистентов

Полный контекст проекта упакован в:

- `AGENTS.md` — правила, команды, ограничения;
- `CONTEXT.md` — краткая карта проекта;
- `docs/ai/` — архитектура, виды спорта, конструктор, анализатор, UI,
  тестирование, сборка, решения, roadmap;
- `docs/ai/generated/` — машинночитаемые каталоги метрик, шаблонов и API;
- `tests/` — портативные регрессии и фикстуры;
- `tools/ui_harness/` — браузерный стенд интерфейса.

Начните с `docs/ai/README.md`. Контекст пересобирается командой
`python tools\dump_ai_context.py`.

## Установка

1. Скопируйте `Predictor-1.15.apk` на телефон (кабель, облако, Telegram «Избранное»).
2. Откройте файл на телефоне.
3. Разрешите установку из неизвестных источников, если система спросит.
4. При первом запуске разрешите уведомления (для сигналов в штрафной строке).

Требования: Android 7.0+ (API 24), 64-битный процессор (arm64-v8a).
Приложение не из Google Play, поэтому Play Protect может показать предупреждение —
это нормально для самодельных APK.

Через ADB:

```powershell
C:\Android\platform-tools\adb.exe install -r Predictor-1.15.apk
```

### Автообновление

При запуске приложение проверяет `GET /api/v1/update` на сайте проекта. Если
там выложена версия с большим `versionCode`, открывается окно с описанием
изменений: APK скачивается, сверяется SHA-256 и передаётся системному
установщику. Обновление можно отложить; обязательное (`mandatory`) — нельзя.

Проверка отключается в «Настройки» → «Обновления приложения». Там же задаётся
адрес манифеста, если сайт расположен не на `predictor.alwaysdata.net`.

Публикация новой версии:

```bash
python tools/publish_release.py app/build/outputs/apk/release/app-release.apk \
    --notes "Что нового"
python tools/prepare_server.py
# загрузить dist/server на alwaysdata (см. server/README.md)
```

`publish_release.py` берёт `versionName`/`versionCode` из
`app/build.gradle.kts`, копирует APK в `releases/`, считает SHA-256 и пишет
`releases/update.json`. Установка обновления поверх другой подписи невозможна:
release-сборка должна быть подписана тем же ключом, что и установленный APK.

## Виды спорта

В приложении шесть видов спорта: настольный теннис, футбол, хоккей,
баскетбол, волейбол и большой теннис. Движок одновременно запрашивает линию
всех видов, проверяет статистику и отправляет прогнозы по каждому из них —
переключать вид для этого не нужно. Активный вид выбирается полосой сверху или
в настройках и влияет только на интерфейс: какие правила, шаблоны и каталог
метрик показывать. Правила конструктора у каждого вида свои и при переключении
не удаляются.

| Вид спорта | id Betcity | Итог матча | Рынки |
|---|---|---|---|
| Настольный теннис | 46 | партии до 11 | П1/П2, ТБ/ТМ партии |
| Футбол | 1 | голы | П1/X/П2, тотал, фора, обе забьют |
| Хоккей | 7 | голы | П1/X/П2, тотал, фора, обе забьют |
| Баскетбол | 3 | очки | П1/П2, тотал, фора |
| Волейбол | 12 | очки | П1/П2, тотал, фора |
| Большой теннис | 2 | геймы | П1/П2, тотал, фора |

Betcity отдаёт счёт с разбивкой по периодам, четвертям, партиям или сетам.
Движок разбирает его в тот же формат, что и настольный теннис, и считает форму
и очные встречи по итоговому счёту. Для тенниса «тотал» — это сумма геймов
матча, для волейбола и баскетбола — очков.

Встроенный алгоритм для командных видов — прозрачный базовый прогноз:
форма за 5 игр, очные встречи и линия тотала Betcity. Тонкие правила
(исход, тотал, фора, обе забьют) задаются в конструкторе.

## Экраны

### Панель
Состояние движка, кнопки **Запустить / Остановить / Проверить**, счётчики
(проверено, сигналов, пропущено, отсечено), hit rate, последние события и
техническая сводка.

### Очередь
Живая линия Betcity: команды, счёт, коэффициенты (в футболе и хоккее — с
ничьей), лига и вид спорта. Фильтры «Все / Скоро / Отправлены / Обработаны».
Кнопка «Обновить» перезапрашивает линию всех видов спорта.
У матчей, на которые уже дан сигнал, прямо в карточке виден сам прогноз:
период/матч, ставка и результат по ней («зашла · 11:7» / «не зашла · 9:11»).

### Результаты
История всех игр с прогнозами. Для каждой игры показаны:
- команды, лига, время сигнала и дата матча, итоговый счёт;
- каждый прогноз (партия и вид ставки), вердикт и статус;
- **обоснование** — какие модели и с какой уверенностью голосовали
  (строка «Модели: …»), уверенность, число согласных моделей, согласие,
  порог тотала;
- результат по партии: счёт, тотал, «зашла / не зашла / ожидает».

Фильтр: вид спорта (Все виды или конкретный), дата и время «с» и «по», быстрые
диапазоны (Сегодня / 7 дней / 30 дней / Всё время), поиск по команде или лиге,
статус (Все / Зашли / Не зашли / Ожидают). На каждой карточке стоит метка вида
спорта. Сводка сверху пересчитывается под выбранный период. Кнопка в шапке
выгружает CSV.

### Логи
Живой журнал с уровнями Info / Warning / Error, поиском по тексту, экспортом и
очисткой. Обновляется автоматически.

### Статистика
Всего прогнозов, hit rate, число матчей, разбивка по видам спорта
(прогнозы / зашли / ожидают) и по видам ставок («Матч · тотал», «Партия 1 ·
П1/П2», «Партия 1 · ТБ/ТМ» и т.д.), список прогнозов с результатами
по каждому рынку, блок экспорта.

### Конструктор
Свой алгоритм прогнозов вместо встроенного ансамбля. Здесь задаются правила вида
«ЕСЛИ … И/ИЛИ … ТО прогноз».

- **Вид спорта** — чипы в начале экрана. У каждого вида свой набор правил,
  шаблонов, метрик и рынков; переключение не удаляет правила других видов.
- **Источник прогнозов** — переключатель «Встроенный алгоритм / Конструктор».
  В режиме конструктора движок шлёт только то, что разрешили ваши правила.
- **Правило** = набор условий (группы можно вкладывать, логика «И»/«ИЛИ») и
  действие. Для настольного тенниса: тотал партии (ТБ/ТМ), победитель партии
  (П1/П2) или пропуск; партии выбираются (1–5 или авто). Для командных видов:
  исход матча (П1/X/П2), тотал матча (ТБ/ТМ), фора (Ф1/Ф2, со знаком) и «обе
  забьют» (да/нет) для футбола и хоккея. Дополнительно: название, приоритет,
  «остановить проверку после правила», уверенность.
- **Метрики** с параметрами: очные встречи (серии, проценты, тоталы,
  последний победитель, число партий, разрывы, сколько дней назад), форма
  игрока/команды за N последних игр (победы, ничьи, тоталы матчей и периодов,
  проценты ТБ, сеты/партии, тренды), сравнение сторон между собой,
  коэффициенты (П1, X, П2, тотал, фора, отношение, вероятность), сам матч
  (час, день недели, минуты до старта, счёт) и таблица тотала со страницы
  статистики. Набор зависит от вида: 75 метрик у настольного тенниса, 68 у
  футбола, 89 у хоккея, по 82 у баскетбола, волейбола и тенниса.
- Любое число можно **сравнить с другой метрикой** («сравнить с метрикой»),
  а не только с константой.
- **Шаблоны** — 100 готовых правил в один тап, с поиском и категориями
  (**Тоталы**, **Победитель**, **Фильтры**, **Комбинированные**). По видам:
  46 — настольный теннис, 11 — футбол, 11 — хоккей, 10 — баскетбол, 10 —
  волейбол, 12 — большой теннис. У каждого шаблона указано обоснование и
  источник; после добавления правило открывается в редакторе, где можно
  поменять порог, сторону, фору и уверенность.
- **Тест на линии** прогоняет правила по текущей линии и показывает, что бы
  сработало и какой прогноз вышел бы, ничего не отправляя;
  **Экспорт/Импорт** правил в JSON.

Шаблоны для настольного тенниса собраны из публичных стратегий и рыночных
ориентиров, для командных видов — из публичной статистики и линии Betcity,
принципов формы, очных встреч и тоталов. Это отправные точки, а не гарантия
прибыли. Перед включением прогоните их кнопкой «Тест на линии», а свою
историю разберите во вкладке «Анализ».

Источники:

- **Beting Rating, «Total in Table Tennis»** — линия 18.5 на партию, 75.5 на
  матч, стратегии «ТБ 18.5 в партии», «ТБ 3.5 / ТМ 4.5 партии», высокий
  индивидуальный тотал фаворита: <https://beting-rating.com/school/total-in-table-tennis/>.
- **DeuceLab, «Table Tennis Betting Markets»** — около двух третей матчей
  проходят дальше трёх партий; чем ровнее матч, тем он длиннее:
  <https://deucelab.io/guides/table-tennis-betting-markets>.
- **PingPongBets, «Over/Under in Table Tennis»** — агрессивная манера игры даёт
  высокие тоталы, защитная — низкие; формат матча влияет на тотал:
  <https://pingpongbets.com/what-is-over-under-betting-in-table-tennis/>.
- **SmartBettingGuide, «Table Tennis Betting Strategy»** — форма, очные
  встречи, усталость от плотного графика и переездов:
  <https://smartbettingguide.com/table-tennis-betting-strategy/>.
- **Table Tennis Totals** — ориентация на статистику ТБ/ТМ и sweep%:
  <https://tabletennistotals.com/learn/>.
- **Betcity** — таблица «Тотал 75.5» и доля ТБ/ТМ со страницы статистики матча.

Статистика круга: число правил, включённых, срабатываний и пропусков.

Данные статистики, на которых работают правила: **5 последних игр каждого
игрока/команды** (счёт, соперники, даты) и **до 10 очных встреч** со страницы
Betcity. Для командных видов дополнительно используются итоговый счёт, счёт по
периодам, линия тотала и коэффициенты (П1/X/П2, тотал, фора).

### Анализатор
Разбор уже сделанных прогнозов: какие параметры статистики чаще совпадают
с **неудачными** прогнозами, а какие — с **успешными**. Нужен, чтобы настраивать
правила конструктора по фактам, а не на глаз.

- Снимок статистики (очные встречи, форма обоих игроков, тоталы страницы,
  коэффициенты) сохраняется **в момент отправки** прогноза — поэтому анализатор
  видит именно те данные, что были у движка, когда он давал прогноз.
- Сверху — счётчики: сколько прогнозов с результатом, сколько зашло и не зашло,
  сколько снимков статистики сохранено.
- Фильтры: **виды спорта галочками** (можно отметить несколько; ничего не
  отмечено — активный вид, кнопки «Только активный» и «Все виды»), вид прогноза
  (все / победитель / тотал / фора / обе забьют), цель (матч или партия 1–5),
  минимум наблюдений в группе (3/5) и минимальный перевес между группами. Для
  командных видов доступна цель «Матч», для настольного тенниса — партии.
  Анализ, проверка правил и рекомендации считаются только по отмеченным видам.
- **Что ограничить в конструкторе** — три самых частых условия неудач с кнопкой
  «Исключить в правиле»: условие сразу переносится в редактор в обратном виде.
- **Неудачные прогнозы** — список условий с долями: «неудачи 12 из 12 · удачи 0%
  · разница 100 п.п.». **Успешные** — то же для зашедших. У каждого условия
  видны примеры матчей и кнопки **«Исключить в правиле» / «Как в удачах»**.
- **Связки из двух условий** — пары параметров, которые срабатывают вместе.
- **Средние значения** — среднее у зашедших против незашедших по каждой метрике
  (сортировка по силе различия).
- «В конструктор» открывает выбор: **создать новое правило** или **добавить
  условие в существующее** (список правил выбранного вида спорта с числом
  условий и приоритетом). Из блока неудач условие **инвертируется** (≤ → >,
  = → ≠), чтобы правило исключало плохую ситуацию; из блока удач — переносится
  как есть. Условие добавляется в корневую группу «И», после чего открывается
  редактор — проверьте правило и сохраните. Если условие уже есть в правиле,
  повторно оно не добавляется.
- Экспорт анализа — JSON со всеми найденными условиями.
- **Что улучшить в правилах** — точные рекомендации с названием правила:
  «Добавить условие „…“ в правило „…“», «Убрать условие», «Отключить правило»,
  «Исправить уверенность». Видно, как изменится точность и сколько срабатываний
  останется. Кнопка применяет правку прямо к актуальному правилу; «Скрыть на
  7 дней» убирает совет. Когда условие уже есть в правиле — в том числе если вы
  добавили его вручную, — рекомендация исчезает при следующем анализе.
  Новые рекомендации помечены и посчитаны отдельно.
- **Проверка активных правил** — отдельная карточка. Каждое включённое правило
  проверяется на истории: точность, средняя по рынку, число срабатываний,
  уверенность и условия. Готовые правки — «Ужесточить», «Расширить», «Поправить
  уверенность», «Отключить» — применяются одной кнопкой и сохраняются в
  конструкторе. Проверка работает и при выключенной авто-генерации и ничего не
  удаляет: отключённое правило можно вернуть.
- **Автоматические правила** — карточка в начале экрана. Кнопка «Включить авто»
  запускает генератор: он группирует историю по рынку и цели, находит условия
  удач и неудач, проверяет точность и покрытие на всей выборке и собирает
  правила конструктора по каждому виду отдельно. Авто-правила помечены значком
  «Авто», пересчитываются не чаще раза в 3 минуты и после новых результатов, а
  слабые заменяются сильными. Ручные правила не изменяются и не удаляются.
  Включение и выключение авто действует сразу на все виды. Точность (55–80%) и
  минимум наблюдений (4–15) настраиваются прямо в карточке; там же видны
  точность, покрытие, число срабатываний и кнопка «Открыть в конструкторе».

Анализатор работает на прогнозах, сохранённых начиная с версии 1.3: у более
ранних прогнозов статистика не сохранялась, и они в разбор не попадают.

### Нейросеть
В приложение встроена небольшая нейросеть — многослойный персептрон, который
работает на телефоне без интернета и без сторонних библиотек.

- **Учится на всех проверенных матчах**, а не только на тех, по которым был
  прогноз: каждый разобранный матч становится примером.
- **Размечает сама**: когда матч завершился, по финальному счёту считаются
  метки (победитель, ничья, тотал), и пример попадает в обучающую выборку.
- **Дообучается постоянно** в фоне: новые результаты не выбрасывают старые,
  модель продолжает учиться. Своя модель у каждого вида спорта.
- **Показывает состояние** на панели: сколько примеров размечено, сколько ждут
  результата, сколько видов готово, точность на отложенной выборке и базовый
  уровень. Там же история обучения (столбики точности, красный — отклонённое
  переобучение), тренд и кнопки «Обучить сейчас», «↩︎ откат» и «Сбросить».
  Под каждым видом — причина, по которой он ещё не обучается: не выбран,
  заморожен, не хватает N примеров, пауза по плато или модель уже готова.
- **Защищена от переобучения:** «оставлять лучшую модель» (новая модель не
  заменит худшую), «заморозить обучение», остановка после 3 раундов без роста
  точности (плато) и откат к предыдущей модели одной кнопкой.
- **Прогнозы по нейросети** включаются переключателем в «Настройках» →
  «Нейросеть». Рядом с переключателем — чипы с галочками по видам спорта:
  сеть даёт прогнозы **только по отмеченным видам** (обучение при этом идёт
  по всем видам). Ниже — чипы **типов ставок по каждому виду**: например, для
  футбола можно оставить только «Тотал» и «Обе забьют». Там же: постоянное
  обучение, минимум примеров для старта (по умолчанию 50) и порог
  уверенности (по умолчанию 55%).
- Сеть использует те же метрики, что и правила конструктора: форма за 5 игр,
  очные встречи, коэффициенты, линия тотала.
- В режиме конструктора ваши правила приоритетнее: сеть не дублирует рынок,
  который уже занят правилом, и добавляет прогнозы по свободным рынкам.

### AI-ассистент
К приложению можно подключить облачную языковую модель — по умолчанию **Gemini**
(бесплатный tier), поддерживаются также DeepSeek, Groq, OpenRouter и любой
OpenAI-совместимый адрес.

- **Объяснить прогноз** — кнопка «🤖» в карточке матча очереди: почему выбран
  исход, на каких данных он основан, какие риски.
- **Собрать правило из анализа** — «🤖 Собрать правило» в «Анализе»: готовое
  правило конструктора из находок анализатора, с кнопкой «В конструктор».
- **Итоги и рекомендации** — «🤖 Итоги» в «Статистике»: что зашло, по каким
  рынкам, что менять.
- **Ревью правил** — «🤖 Ревью» в «Правилах»: противоречия и лишние условия.
- **ИИ-прогнозы по линии** (по желанию) — модель получает данные матча и отдаёт
  своё мнение. В настройках можно выбрать виды спорта и отдельные типы ставок
  для каждого вида. Переключатель **«Добавлять ИИ-прогноз в текущий»** встраивает
  мнение в сообщение с прогнозами правил или сети и не создаёт отдельных
  сообщений; если прогноза нет, запрос не тратится. Мнение не участвует в
  расчёте ставки, но сохраняется в истории и проверяется по финальному счёту —
  так можно честно сравнить ИИ с правилами.

Экономия: запросы идут только по кнопке, ответы кэшируются, есть дневной лимит
и лимит на цикл движка. Без ключа или без сети приложение работает как обычно.
Ключ хранится только на телефоне.

**Чат и постоянный помощник** (кнопка «💬 Спросить» на панели):
- **Задавайте вопросы** о приложении: почему нет прогнозов, что означает
  настройка, как настроить правила или нейросеть. Помощник получает справку о
  текущем состоянии (правила, нейросеть, результаты, настройки) и подходящие
  статьи документации — отвечает в контексте вашего приложения, а не «вообще».
- **Помощник сам следит за приложением** и подсказывает, что поправить:
  нейросеть переобучается (→ заморозить обучение), сеть хуже базового уровня
  (→ выключить её для вида), правило чаще проигрывает (→ выключить конкретное
  правило), у вида нет включённых правил, в логе много ошибок, обучение встало
  на плато, мнение ИИ заходит чаще правил, слишком частый опрос линии.
  У каждой рекомендации есть кнопка — приложение выполняет её само.
- Проверки помощника локальные: они работают **даже без ключа и без сети** и
  ничего не стоят. Опасных действий (сброс данных, сброс модели) он не
  предлагает — только ручные.

### Документация
Встроенное руководство по приложению — отдельная вкладка «Документация» в нижнем
меню. Внутри 30 статей в группах **Старт**, **Правила**, **Анализ**, **Очередь
и итоги**, **Настройки**, **Справочник** и **Вопросы**.

- Поиск по заголовкам, тексту и таблицам с подсветкой найденного и сниппетами;
  фильтры по группе и типу статьи (руководство, справочник, чек-лист, FAQ).
- Полный справочник полей правила: название, приоритет, включение, «стоп после
  правила», группы «И/ИЛИ», все операторы, сравнение с метрикой, действия и
  авто-выбор стороны, уверенность, шаблоны, тест на линии.
- Справочник метрик **динамический**: подгружается каталог активного вида
  спорта, есть поиск по названию и группировка (форма, очные, коэффициенты,
  матч, тоталы). При смене вида спорта список обновляется.
- Разбор анализатора: как читать доли, перевес, покрытие и связки; как
  переносить условия в правила; недельный цикл настройки.
- Отдельная статья о проверке активных правил: вердикты, готовые правки,
  ограничения малой выборки.
- Отдельная статья об авто-правилах: включение, построение условия, пороги
  точности и наблюдений, непрерывная доработка, контроль и откат.
- Отдельная статья о нейросети: цикл обучения, что показывает карточка на
  панели, настройки и совместная работа с правилами.
- Отдельная статья об AI-ассистенте: подключение ключа, четыре функции
  (объяснение, черновик правила, итоги, ревью) и ИИ-прогнозы по линии.
- Очередь, результаты, статистика, все настройки с значениями по умолчанию,
  рынки и расчёт ставок, глоссарий, логи, FAQ и чек-лист перед включением.
- Оглавление статьи, переходы «назад/вперёд», связанные статьи и контекстные
  кнопки «?» в конструкторе и анализаторе.

### Настройки
Все параметры движка:

- **вид спорта** — активный вид для интерфейса и правил; движок анализирует и отправляет прогнозы по всем видам;
- **источник прогнозов** — встроенный алгоритм или конструктор;
- интервал опроса линии (5–600 с);
- матчей на вид за цикл (0–50, по умолчанию 10) — ограничение нагрузки при
  одновременном разборе всех видов; остальные матчи ждут следующего цикла;
- проверка коэффициентов, подробный лог, размер ставки;
- **нейросеть**: прогнозы по нейросети (вкл/выкл), виды спорта для
  прогнозов (чипы с галочками), типы ставок по каждому виду (чипы с
  галочками), постоянное обучение, оставлять лучшую модель, заморозить
  обучение, примеров для обучения (10–2000), порог уверенности (50–95%),
  партий в прогнозе настольного тенниса (1–5);
- **AI-ассистент**: облачная модель (провайдер, адрес, модель, ключ, таймаут),
  ИИ-прогнозы по линии, виды спорта и типы ставок для ИИ, «добавлять ИИ-прогноз
  в текущий», запросов за цикл (0–5), запросов в день (0–1000), порог
  уверенности ИИ;
- Telegram: включение, токен, chat id;
- **онлайн-режим**: адрес сайта, токен доступа, таймаут, локальный расчёт при
  ошибке, проверка сертификата HTTPS, кнопка «Проверить подключение»;
- для настольного тенниса — пороги шести моделей (streak, window, markov1,
  markov2, recency, base_rate), обязательные модели, виды ставок
  (П1, П2, ТБ 18.5, ТМ 18.5) и партии (1–5); для командных видов эти блоки
  скрыты, потому что встроенный алгоритм использует форму, очные встречи и
  линию тотала;
- общие фильтры: согласные модели, согласие, уверенность, активные модели,
  вес голоса, минимум очных встреч;
- параметры моделей: серия, окно, попадания, выборка Маркова, затухание
  свежести, выборка базовой частоты;
- отчёты: ежечасный, дневной (час и минута);
- уведомления: сигнал, результат, ошибки;
- очистка данных.

Кнопка «Сохранить настройки» применяет изменения сразу — перезапуск не нужен.

3. Впишите оба значения в Настройки → Telegram и включите переключатель.

## Онлайн-режим (необязательно)

По умолчанию всё считается на телефоне. Кнопка **«Использовать онлайн»** на
экране «Анализ» отправляет снимок истории, правил и состояния рекомендаций на
сайт; сайт считает **тот же отчёт тем же Python-кодом** и возвращает анализ,
проверку правил и рекомендации. Телефон показывает результат, как обычно.

- Адрес сайта и токен задаются в «Настройках» → «Онлайн-режим».
- «Проверить подключение» показывает задержку и версию сервера.
- Если сайт недоступен, приложение считает локально (переключатель
  «Локальный расчёт при ошибке»); в карточке видна последняя ошибка.
- На сайте нет базы данных: история не сохраняется, каждый запрос
  самодостаточен.
- Готовый WSGI-сервис и пошаговая инструкция для alwaysdata.com —
  в `server/README.md`; папка для загрузки собирается командой
  `python tools\prepare_server.py`.

## Как это работает

```
Android UI (WebView)
        │  window.PyApp.*
        ▼
MainActivity.kt  ──►  engine_api.py  ──►  predictor_core.py
        │                                      │
        │                                      ├─ Betcity API (линия)
        │                                      ├─ betcity.by/ru/mstat (статистика:
        │                                      │      5 игр игрока + очные + тоталы)
        │                                      ├─ constructor_engine.py (правила)
        │                                      └─ predictor_data/ (настройки, логи, CSV)
        ▼
EngineService (foreground) — не даёт системе выгрузить процесс
```

Движок работает в одном из двух режимов (переключатель в «Настройках» и в
«Конструкторе»): **встроенный** — ансамбль шести моделей, как в оригинальном
скрипте, или **конструктор** — только правила пользователя.

Данные лежат в приватной папке приложения:
`/data/data/by.betcity.predictor/files/predictor_data/`
(правила конструктора — `constructor_rules.json` для настольного тенниса и
`constructor_rules_<sport>.json` для остальных видов).

Запуск движка поднимает foreground-сервис с постоянным уведомлением — Android
не убивает процесс, пока идёт анализ. После перезапуска процесса сервис
автоматически поднимает движок, если он был включён.

## Отличия от исходного скрипта

1. **Telegram не обязателен** — хранилище прогнозов работает всегда.
2. **Данные** пишутся в приватную папку приложения, а не в текущий каталог.
3. **Цикл** управляется кнопками: старт, стоп, ручная проверка.
4. **Логи** идут в кольцевой буфер (2000 событий) и файл `predictor.log`.
5. **Исправлены два бага оригинала:**
   - результаты «победитель» и «тотал» одной партии перезаписывали друг друга;
   - счёт через пробел (`11:7 9:11`) не разбирался.
6. Логика моделей, фильтров и парсинга сохранена.

Дополнительно в приложении:

7. **Шесть видов спорта** — настольный теннис, футбол, хоккей, баскетбол,
   волейбол и большой теннис. У каждого свои правила, шаблоны, рынки и разбор
   счёта.
8. **Конструктор правил** — свой алгоритм прогнозов: условия по статистике
   (5 последних игр, очные встречи, коэффициенты, тоталы) и действия
   (ТБ/ТМ, П1/X/П2, фора, обе забьют, пропуск). Режим выбирается переключателем.
9. **Статус-бар** всегда скрыт, а его цвет (если система его покажет) совпадает
   с фоном приложения.
10. **Очередь и результаты** дополнены показом прогноза, обоснования и итога
   по каждой партии (в том числе для прогнозов конструктора).
11. **Встроенная документация** с поиском, фильтрами, полным справочником
   правил и динамическим списком метрик; из анализатора условие можно добавить
   как в новое, так и в существующее правило.
12. **Автообновление APK** — проверка манифеста при запуске, докачка с
   контролем SHA-256 и установка через системный установщик.
