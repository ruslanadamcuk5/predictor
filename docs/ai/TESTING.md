# TESTING — проверка проекта

## 1. Что проверяется сейчас

На машине разработки нет Android-устройства или эмулятора. Поэтому проверены:

- Python-логика через `tests/`;
- WebView-интерфейс через браузерный стенд;
- сборка, подпись и содержимое APK.

Не проверено: запуск Chaquopy на реальном телефоне, реальная линия в
приложении, системные уведомления, foreground-сервис, переключение видов на
устройстве, установка автообновления поверх предыдущей версии.

## 2. Окружение

```powershell
$env:PYTHONUTF8="1"
$env:PYTHONIOENCODING="utf-8"
```

Python 3.13. Chaquopy собирает `app.imy` тем же buildPython, который указан в
`app/build.gradle.kts`. Скрипт ищет Python 3.13 автоматически; на другой машине
путь можно задать переменной `CHAQUOPY_BUILD_PYTHON`.

PowerShell показывает `RequestsDependencyWarning` и завершает команду с кодом
1 даже при успешном тесте. Смотрите итоговую строку теста.


   - активный вид в верхней панели — футбол;
   - панель по-прежнему показывает «Матчей во всех видах»;

   виден.
5. Возврат на настольный теннис: TT-карточки снова видны, «Партии» видны.
6. Очередь, результаты, статистика, конструктор — без ошибок. В очереди матчи
   разных видов, у каждого своя метка, заголовок «Все виды».
7. «Анализ» → карточка авто:
   - выключено: бейдж «выкл», кнопка «Включить авто», активны пороги 60%/6;

   - выключение убирает авто-правила из списка;
   - включение/выключение действует на все виды, но ручные правила не трогает.
8. «Документация»: 28 статей, статья «Автоматические правила» открывается из
   анализатора и из поиска, статья «Нейросеть» — тоже.
9. Карточка «Нейросеть» на панели:
   - бейдж «выкл», счётчики примеров и ожидающих результат;

    (50), порога (55) и партий (3); сохранение работает, снятая отметка вида

На 22.10.2026 стенд прошёл эти проверки с 0 ошибок консоли.

## 6. Проверка на устройстве

Требуется arm64 Android 7.0+ (или x86_64 эмулятор).

```powershell
adb install -r ..\Predictor-1.15.apk
adb logcat -c
adb shell am start -n by.betcity.predictor/.MainActivity
adb logcat | Select-String -Pattern "python|chaquopy|betcity|Predictor"
```

Чек-лист:

01. Приложение запускается, статус-бар скрыт.
02. Панель показывает версию 1.15, активный вид и число матчей во всех видах.
03. «Проверить» возвращает Betcity: ok и суммарное число матчей; в сводке есть
    `sports` и `by_sport` для нескольких видов.
04. Переключение всех 6 видов не роняет приложение и не останавливает анализ.
05. Очередь показывает линию всех видов, у каждого матча своя метка и счёт в
    правильном формате.
06. «Запустить»: движок работает, уведомление foreground видно. Через 1–2
    цикла в логах «Всего матчей … видов: N»; при настроенных правилах прогнозы
    приходят минимум по двум видам без переключения активного вида.
07. Конструктор:
    - для каждого вида свой набор метрик и рынков;
    - шаблоны добавляются;
    - правило сохраняется и остаётся после перезапуска;
    - «Тест на линии» не падает.
08. Переключение вида не удаляет правила других видов.
09. Результаты: фильтры по виду, дате, поиску, статусу работают.
10. Статистика: разбивка по видам совпадает с результатами.
11. Анализатор: фильтры скрываются по виду; «В конструктор» предлагает новое
    правило или существующее; условие появляется в редакторе, после сохранения
    правило подсвечивается.
12. Авто-правила:
    - включение переключает режим на конструктор, статус «вкл»;
    - при малой истории показывается подсказка, приложение не падает;
    - «Обновить сейчас» пересчитывает и показывает точность/покрытие;
    - выключение оставляет ручные правила включёнными, авто — выключенными;
    - повторное включение снова создаёт авто-правила;
    - авто-правила появляются в нескольких видах, у каждого свои;
    - после перезапуска настройка `auto_rules.enabled` сохраняется.
13. Нейросеть:
    - карточка на панели показывает число примеров и ожидающих результат;
    - число размеченных примеров растёт после разбора матчей;
    - «Обучить сейчас» не вешает интерфейс, бейдж показывает «учится»;
    - после 50+ размеченных матчей на вид появляются прогнозы сети;
    - прогноз сети в результатах помечен источником «Нейросеть»;
    - **прогнозы сети приходят только по отмеченным видам**: сняли отметку с
      вида — сигналов по нему нет, остальные виды работают;
    - **типы ставок соблюдаются**: сняли «Тотал» у футбола — в прогнозах сети
      по нему тотала нет, остальные рынки остались;
    - **защита от переобучения**: в истории есть столбики, красный столбик
      означает отклонённую модель, метка «плато» появляется после трёх
      раундов без роста точности; обучение вида само возобновляется, когда
      примеров становится на 25% больше (проверить по логу);
    - карточка показывает точность по исходу и число проверочных примеров;
      при менее 40 примерах есть пометка «мало — цифра шумная»;
    - **разметка по последнему счёту**: если матч ушёл из линии до проверки,
      пример всё равно размечен (счётчик «не удалось разметить» не растёт
      на каждом матче); в логе нет ошибок разметки;
    - «↩︎ откат» возвращает предыдущую модель (точность в карточке меняется);
    - «Заморозить обучение» останавливает автоматическое дообучение, но
      кнопка «Обучить сейчас» работает;
    - «Сбросить» очищает примеры и модели, счётчики обнуляются;
    - обучение продолжается при остановленном движке (разметка идёт).
14. AI-ассистент:
    - в настройках появляются чипы провайдеров, поля ключа и лимитов, кнопка
      «Проверить подключение»;
    - «🤖» в карточке матча открывает объяснение (окно с текстом);
    - «🤖 Собрать правило» в «Анализе» возвращает JSON правила и кнопку
      «В конструктор»;
    - «🤖 Итоги» в «Статистике» и «🤖 Ревью» в «Правилах» отвечают;
    - без ключа кнопки дают понятную ошибку, приложение не падает;
    - мнение ИИ в сообщении помечено «🤖 МНЕНИЕ ИИ», в «Результатах» — строкой
      с пометкой «🤖».
15. Документация: вкладка открывается, 29 статей, поиск и фильтры работают;
    статья «Справочник метрик» подгружает метрики активного вида; статья
    «Автоматические правила» доступна из анализатора; статья «Нейросеть»
    открывается из поиска; текст читается, таблицы прокручиваются, нижнее меню
    из 9 пунктов не переполняется.
16. Логи: уровни, поиск, очистка, экспорт.
17. Настройки: сохранение и сброс.
18. Экспорт: отчёты, CSV, JSON, логи, правила.
19. «Остановить»: сервис и уведомление исчезают.
20. Проверка результата: прогноз закрывается по завершённому матчу, для
    форы push не считается ни победой, ни поражением.
21. Проверка по кэшу: дайте матчу завершиться и подождите, пока Betcity уберёт
    его из линии (обычно 1–3 минуты). Прогноз должен закрыться сам:
    - в карточке появляется метка «по кэшу», в строке прогноза — «по
      последнему счёту из линии»;
    - в результатах нет «вечного ожидания» по этому матчу;
    - для настольного тенниса закрываются все партии, а матчевый прогноз ИИ —
      по 4 победам в партиях;
    - если счёт был неполным, прогноз честно остаётся «в ожидании».
22. Мнение ИИ: включите «ИИ-прогнозы по линии», дождитесь матча с прогнозом.
    Строка «🤖» в результатах должна закрыться (или остаться «в ожидании»,
    но не получить неверный исход), а сводка показать «ИИ: N (победы/поражения)».
23. Поворот экрана/фон: приложение не теряет состояние критично.
24. Кнопки «?» в конструкторе и анализаторе открывают нужную статью, системная
    кнопка «Назад» возвращает из статьи к списку, а не закрывает приложение.

Результат чек-листа зафиксируйте в `ROADMAP.md`.

## 8. Что считается неудачей

- Ошибка импорта Python на устройстве (`ModuleNotFoundError`).
- Пустой каталог метрик или шаблонов для вида.
- Падение при переключении вида.
- Прогноз без снимка статистики (анализатор не увидит данные).
- Ошибка сохранения правил (`ok: false`).
- Чёрный/пустой WebView после запуска.
- Утечка реального `token`/`chat_id` в логи или экспорт.
