# GLOSSARY — термины

## Домен

| Термин | Значение |
|---|---|
| Live-линия | текущие матчи и коэффициенты Betcity |
| Матч | событие из live-фида |
| Партия / сет / период / четверть | часть матча; зависит от вида |
| H2H | очные встречи (head-to-head) |
| Форма | результаты последних N игр |
| Тотал | сумма очков/голов/геймов |
| Фора | гандикап со знаком |
| Обе забьют (ОЗ) | обе стороны набрали больше нуля |
| П1 / X / П2 | победа первой стороны / ничья / победа второй |
| Прогноз | конкретное утверждение: рынок + сторона + порог |
| Вердикт | текстовое представление прогноза («ТБ 2.5», «П1») |
| Push / возврат | результат точно на границе форы; не победа и не поражение |
| Hit rate | доля зашедших прогнозов среди завершённых |
| Шаблон | готовое правило-заготовка |
| Правило | пользовательская логика «ЕСЛИ … ТО …» |
| Метрика | вычисляемое число/строка/флаг из статистики |
| Условие | метрика + оператор + значение |
| Действие | прогноз, который выдаёт правило |
| Анализатор | разбор истории прогнозов по условиям |
| Активный вид | вид спорта, который опрашивает движок |

## Идентификаторы

| Ключ | Значение |
|---|---|
| `table_tennis` | настольный теннис, Betcity 46 |
| `football` | футбол, Betcity 1 |
| `hockey` | хоккей, Betcity 7 |
| `basketball` | баскетбол, Betcity 3 |
| `volleyball` | волейбол, Betcity 12 |
| `tennis` | большой теннис, Betcity 2 |
| `match` | цель прогноза — весь матч |
| `set1`..`set5` | цель — партия/сет |
| `p1` / `p2` | первая / вторая сторона |
| `x` | ничья |
| `over` / `under` | больше / меньше тотала |
| `yes` / `no` | обе забьют / не забьют |
| `btts` | рынок «обе забьют» |
| `handicap` | рынок «фора» |

## Форматы

| Термин | Значение |
|---|---|
| `app.imy` | собранный Chaquopy образ Python-модулей |
| `assets/www` | WebView-интерфейс внутри APK |
| `predictor_data` | папка данных приложения |
| `events.jsonl` | события экрана «Логи» |
| `sent_predictions.json` | прогнозы, снимки, результаты |
| `constructor_rules_<sport>.json` | правила вида |
| JSON-safe | значение, которое можно сериализовать в JSON |
| `__dt__` | маркер восстановления datetime в анализаторе |

## Сокращения

| Сокращение | Расшифровка |
|---|---|
| TT | настольный теннис |
| H2H | очные встречи |
| ОЗ | обе забьют |
| ТБ / ТМ | тотал больше / тотал меньше |
| Ф1 / Ф2 | фора первой / второй стороны |
| П1 / П2 | победа первой / второй стороны |
| X | ничья |
| LLD | Low-Level Discovery в Zabbix (другой проект) |
| RMS | система мониторинга (другой проект) |
