# AI Context — Betcity Predictor Android

Папка содержит полный контекст разработки, упакованный так, чтобы новая модель
ИИ или разработчик могли продолжить проект без истории чата.

## Порядок чтения

1. `AGENTS.md` в корне проекта — правила и быстрые команды.
2. `CONTEXT.md` в корне — краткая карта на одну страницу.
3. `PROJECT.md` — что делает приложение и в каком оно состоянии.
4. `ARCHITECTURE.md` — как устроены слои и потоки данных.
5. `SPORTS.md` — виды спорта и различия между ними.
6. `CONSTRUCTOR.md` — правила конструктора и расчёт прогнозов.
7. `ANALYZER.md` — анализатор истории.
8. `UI.md` — WebView-интерфейс и мост.
9. `TESTING.md` — как проверять.
10. `BUILD_RELEASE.md` — как собрать и выпустить APK.
11. `DECISIONS.md`, `ROADMAP.md`, `CHANGELOG.md`, `GLOSSARY.md`.

## Машинночитаемые данные

`generated/` создаётся командой:

```powershell
python tools\dump_ai_context.py
```

Файлы:

- `summary.json` — сводка по видам: id Betcity, число метрик, шаблонов,
  рынки, тотал по умолчанию, число вариантов анализатора;
- `sports_catalog.json` — публичный каталог видов спорта;
- `metrics/<sport>.json` — все метрики вида, аргументы, операторы, рынки;
- `presets/<sport>.json` — все готовые шаблоны с условиями и действиями;
- `api_endpoints.json` — функции Python-API и их сигнатуры;
- `PROJECT_TREE.txt` — дерево значимых файлов без вендоренных библиотек.

Не редактируйте `generated/` вручную: измените код и перезапустите скрипт.

## Что считать источником истины

Код → тесты → `generated/` → документация → README.

## Если вы новая модель

Начните с `AI_PROMPT.md`: там готовый текст для первого сообщения. Затем
прочитайте `PROJECT.md`, `ARCHITECTURE.md` и только после этого открывайте
конкретные файлы, которые упомянуты в задаче.
