# PROJECT — Betcity Predictor Android

## 1. Назначение

Мобильное приложение для самостоятельного анализа live-линии Betcity и выдачи
прогнозов по шести видам спорта. Работает автономно: Python-ядро встроено в APK
через Chaquopy, сервер не требуется. Прогнозы можно смотреть в приложении,
получать уведомлением или отправлять в Telegram (необязательно).

Пользователь: один человек, который хочет держать телефон включённым, получать
сигналы сразу по всем видам спорта и настраивать собственную логику прогнозов.

## 2. Что умеет приложение

- Получать live-линию Betcity по всем видам спорта одним запросом.
- Загружать статистику матча: последние 5 игр каждого игрока/команды, до 10
  очных встреч, таблицу тоталов со страницы Betcity.
- Считать прогнозы:
  - встроенный алгоритм: ансамбль шести моделей для настольного тенниса;
  - для командных видов — прозрачный базовый прогноз по форме, очным встречам
    и линии тотала;
  - конструктор: пользовательские правила.
- Отправлять сигналы в Telegram и/или системным уведомлением.
- Проверять результаты завершённых матчей и обновлять статистику.
- Вести очередь, историю результатов, статистику по видам спорта и рынкам.
- Хранить готовые шаблоны правил (100 штук).
- Разбирать историю прогнозов в анализаторе: какие условия чаще сопутствуют
  успеху и неудаче.
- Автоматически строить и дорабатывать правила по накопленной статистике,
  не изменяя ручные правила.
- Обучать встроенную нейросеть на всех проверенных матчах, показывать объём
  данных и точность модели и выдавать по ней прогнозы (переключатель в
  настройках, выбор видов спорта и типов ставок по каждому виду).
- Экспортировать отчёты, CSV, JSON, логи, настройки, правила и анализ.

## 3. Экраны

Нижняя навигация (9 пунктов): **Панель**, **Очередь**, **Результаты**,
**Логи**, **Статистика**, **Правила**, **Анализ**, **Настройки**,
**Документация**. Статус-бар Android скрыт; приложение полноэкранное.

### Панель

Состояние движка, кнопки «Запустить / Остановить / Проверить», счётчики
(проверено, сигналов, пропущено, отсечено), hit rate, последние события,
техническая сводка, активный вид для правил и общее число матчей по всем видам.

### Очередь

Live-линия всех видов: команды, счёт, коэффициенты (П1/X/П2, тотал),
лига, метка вида спорта. Фильтры «Все / Скоро / Отправлены / Обработаны».
У отправленных матчей виден прогноз и результат по конкретному матчу.

### Результаты

История игр с прогнозами. Для каждой игры: команды, лига, время, итоговый счёт,
вид спорта, каждый прогноз, вердикт, статус, обоснование, результат.
Фильтры: вид спорта, дата/время, быстрые диапазоны, поиск, статус. Экспорт CSV.

### Логи

Живой журнал уровней Info/Warning/Error/Success, поиск, экспорт, очистка.
Технические подробности моделей и парсинга.

### Статистика

Всего прогнозов, hit rate, число матчей, разбивка по видам спорта и по рынкам
(`Матч · тотал`, `Партия 1 · П1/П2` и т.п.), список последних прогнозов.

### Конструктор

Свой алгоритм вместо встроенного. Правила вида «ЕСЛИ … И/ИЛИ … ТО прогноз».
Переключатель источника прогнозов, вид спорта, список правил, редактор условий и
действий, шаблоны, тест на линии, экспорт/импорт JSON.

### Анализ

Разбор накопленных прогнозов: частые условия неудач и успехов, связки, средние
значения, перенос условия в конструктор (неудачи инвертируются). При переносе
можно создать новое правило или добавить условие в существующее. Фильтры по
виду спорта, рынку, цели, минимальной группе и перевесу. Карточка
«Автоматические правила» включает генератор, показывает точность/покрытие,
позволяет менять пороги и обновлять правила вручную; ручные правила не
затрагиваются.

### Документация

Встроенное руководство: 27 статей с поиском и фильтрами по группе и типу,
полный справочник полей правила, динамический справочник метрик активного вида,
разбор анализатора и авто-правил, очередь/результаты/статистика, настройки,
рынки, глоссарий, FAQ и чек-лист. Статьи связаны переходами и контекстными
кнопками «?».

### Настройки

Активный вид спорта, интервал опроса, проверка коэффициентов, подробный лог,
размер ставки, Telegram, пороги моделей и фильтры (для настольного тенниса),
отчёты, уведомления, очистка данных.

## 5. Границы проекта

- Нет облака и синхронизации между устройствами.
- Нет авторизации Betcity и ставок реальными деньгами.
- Активный вид влияет только на интерфейс; движок одновременно опрашивает и
  анализирует все шесть видов спорта.
- Нет iOS-версии.
- Telegram не обязателен; без него прогнозы хранятся локально.
- Приложение не гарантирует прибыль; шаблоны — стартовые точки.

- `.backups/` — резервные копии перед крупными изменениями.

## 7. Ближайшая цель

Установить APK на arm64 Android 7.0+, проверить переключение видов спорта,
Chaquopy-импорты, реальную линию, сохранение правил, анализатор, документацию
в WebView и привязку условия к существующему правилу. После этого
зафиксировать результат в `ROADMAP.md`.
