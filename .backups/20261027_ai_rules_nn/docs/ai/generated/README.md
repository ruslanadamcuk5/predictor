# generated — машинночитаемый контекст

Не редактируйте файлы вручную. Они создаются командой из корня проекта:

```powershell
python tools\dump_ai_context.py
```

Скрипт подменяет `HOME` на временную папку и не трогает рабочие данные
приложения.

| Файл | Содержимое |
|---|---|
| `summary.json` | сводка по видам: id, Betcity id, число метрик/шаблонов, рынки, тотал, варианты анализатора |
| `sports_catalog.json` | публичный каталог видов (`sports.public_catalog`) |
| `metrics/<sport>.json` | все метрики вида: id, подпись, группа, тип, аргументы, единица, подсказка; плюс операторы, аргументы, рынки, подписи сторон |
| `presets/<sport>.json` | все шаблоны вида с условиями и действиями |
| `api_endpoints.json` | функции `engine_api.api_*`, их сигнатуры и первая строка docstring |
| `PROJECT_TREE.txt` | дерево значимых файлов без вендоренных библиотек и артефактов |

Когда перезапускать:

- добавлена/удалена метрика;
- изменены виды или рынки;
- добавлены/изменены шаблоны;
- изменились сигнатуры `api_*`;
- заметно изменилась структура проекта.

Проверка после генерации:

```powershell
python -c "import json,io; d=json.load(io.open('docs/ai/generated/summary.json',encoding='utf-8')); print({k:v['metrics'] for k,v in d['sports'].items()})"
```
