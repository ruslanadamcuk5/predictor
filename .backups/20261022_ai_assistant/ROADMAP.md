# ROADMAP — состояние и планы

Дата среза: 22.10.2026. Версия: 1.11.

## 1. Сделано

### Продукт

- Шесть видов спорта: настольный теннис, футбол, хоккей, баскетбол,
  волейбол, большой теннис.
- Движок анализирует все шесть видов сразу; активный вид — только интерфейс и
  выбор правил. Правила и шаблоны хранятся отдельно на вид.
- Live-линия Betcity по всем видам одним запросом, статистика, коэффициенты,
  счёт.
- Встроенный алгоритм: TT-ансамбль и generic для остальных.
- Конструктор: метрики, условия, рынки, шаблоны, тест на линии,
  импорт/экспорт.
- Очередь, результаты с фильтрами, статистика по видам и рынкам.
- Анализатор истории и перенос условий в конструктор: новое правило или
  добавление в существующее.
- Авто-формирование правил: генерация по истории, пороги точности/выборки,
  непрерывный пересчёт, сохранение ручных правил.
- Нейросеть: обучение на всех проверенных матчах, разметка по финальному
  счёту, фоновое дообучение, карточка на панели, переключатель прогнозов в
  настройках, выбор видов спорта и типов ставок по каждому виду, защита от
  переобучения (keep_best, freeze, плато, откат).
- AI-ассистент: облачная модель (Gemini по умолчанию, DeepSeek/Groq/
  OpenRouter/свой endpoint) — объяснение прогноза, черновик правила из
  анализа, итоги и рекомендации, ревью правил, ИИ-прогнозы по линии
  отдельным источником.
- Встроенная документация: 29 статей, поиск, фильтры, динамический справочник
  метрик, контекстные кнопки «?».
- Логи, ошибки, экспорт, очистка.
- Настройки, Telegram, отчёты, уведомления.
- 100 шаблонов правил, 0 ошибок валидации.

### Инженерное

- 15 офлайн-наборов в `tests/run_all.py`, фикстуры страниц Betcity.
- Браузерный UI-стенд в `tools/ui_harness`.
- Генератор контекста `tools/dump_ai_context.py` и `docs/ai/`.
- APK 1.9 собран, подписан debug-ключом, содержимое проверено.
- Версия синхронизирована: `APP_VERSION 1.11.0`, `versionName 1.11`,
  `versionCode 12`.

## 6. Риски

| Риск | Влияние | Смягчение |
|---|---|---|
| Изменение разметки Betcity | парсеры падают, прогнозов нет | фикстуры + быстрый регресс, логи парсинга |
| Смена ID/структуры live API | ни один вид не грузится | `sports.py` — единая точка, тест `test_sports_pipeline` |
| Ошибка в Chaquopy-сборке | приложение не стартует | проверка `app.imy` перед установкой |
| Синхронный мост | фризы UI на медленной сети | сеть только в фоне/по действию |
| Мало данных у анализатора | слабые выводы | минимум 3 успеха и 3 неудачи, честный `hint` |
| Debug-подпись | нельзя опубликовать | release keystore перед релизом |
| Большой APK (~40 МБ) | долгая установка | вендоренные пакеты, при росте — вынести лишнее |
| Потеря данных при uninstall | история и правила исчезают | регулярный экспорт JSON |

## 7. Открытые вопросы

- Нужна ли синхронизация истории между устройствами? Пока нет.
- Нужно ли несколько активных видов с разделением интервалов? Пока нет.
- Стоит ли автоматически отключать шаблон с плохим hit rate? Пока решение
  за пользователем.
- Нужна ли отправка прогнозов в Telegram для командных видов по умолчанию?
  Сейчас Telegram общий для всех видов.
