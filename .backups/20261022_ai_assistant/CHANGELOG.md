# CHANGELOG

История проекта. Артефакты APK лежат в `..` относительно корня проекта,
исходники промежуточных версий — в `.backups/`.

## 1.11 — 22.10.2026

**Тема:** полноценный AI-помощник — чат с вопросами и постоянный контроль
состояния приложения.

Добавлено:

- `ai_inspector.py`: автономные проверки состояния приложения — переобучение
  и плато нейросети, сеть хуже базового уровня, примеры без результатов,
  отсутствие включённых правил, проигрывающее правило (по данным
  анализатора), ошибки в логе, мнение ИИ против правил, частый опрос линии,
  выключенная проверка коэффициентов; у каждой находки — готовое действие;
- **чат с помощником** («💬 Спросить» на панели): вопросы о приложении,
  ответ строится по справке о текущем состоянии (правила, нейросеть,
  результаты, настройки без секретов) и по найденным статьям документации;
  история диалога сохраняется на устройстве;
- **карточка «Помощник»** на панели: список находок с важностью и кнопкой
  действия («Заморозить обучение», «Выключить правило», «Выключить сеть для
  вида», «Включить проверку коэффициентов» и другие);
- `AIAssistant.passport()` — справка о приложении для модели;
- `AIAssistant.answer()` — сборка промпта: справка + документация + история
  диалога + вопрос;
- API: действия `chat`, `messages`, `inspect`, `apply` в `api_ai`,
  `Engine.advice()` и `ai_inspector.apply_action()`;
- `tests/test_ai.py` вырос до 75 проверок (чат, справка, помощник, действия,
  переключение провайдера).

Исправлено:

- **переключение провайдера ИИ**: чик «DeepSeek» (и любой другой) теперь
  реально подставляет свой адрес API и модель, а выбор не сбивается фоновым
  опросом состояния, пока вы правите настройки. На сервере адрес и модель
  сверяются с пресетами: если в полях остались значения другого провайдера,
  они заменяются автоматически. Свой endpoint пользователя не трогаем;
  для него ключ больше не обязателен (Ollama/LM Studio).
- **диагностика подключения ИИ**: «Проверить подключение» больше не
  показывает обезличенное «нет ответа от модели», а конкретную причину —
  `HTTP 401: Authentication Fails...`, `model not found`, «превышено время
  ожидания», «не найден адрес сервера» и т.п. Ошибка дублируется в «Логах».
  Тест подключения идёт без «размышления» (быстро), добавлен переключатель
  «Размышление модели», таймаут по умолчанию 90 с (макс. 300), ожидание
  ответа в чате увеличено до 180 с.

Изменено:

- версия: `APP_VERSION 1.11.0`, `versionCode 12`, `versionName 1.11`;
- документация: статья «AI-ассистент» дополнена разделами «Чат с
  помощником» и «Помощник: что он проверяет сам».

Проверено: Python-регрессии (15/15), браузерный стенд (карточка
помощника, чат, применение действия), сборка APK. Не проверено: ответы
реальной модели с ключом на устройстве.

## 1.9 — 22.10.2026

**Тема:** встроенная нейросеть с постоянным самообучением.

Добавлено:

- `nn_core.py`: признаки из метрик конструктора (форма, очные встречи,
  коэффициенты, линия тотала), разбор финального счёта в метки, многослойный
  персептрон с сигмоидными выходами (П1 / П2 / ничья / тотал), стандартизация
  признаков, mini-batch SGD с импульсом и оценка точности на отложенной
  выборке;
- `nn_trainer.py`: сбор примеров по **всем проверенным матчам** (в том числе
  без прогноза), файл ожидающих результат, разметка по финальному счёту,
  фоновая нить постоянного дообучения, слияние прогнозов сети с другими
  источниками, сохранение моделей;
- карточка «Нейросеть» на панели: объём данных, ожидающие результат, готовые
  виды, точность против базового уровня, кнопки «Обучить сейчас» и «Сбросить»;
- карточка «Нейросеть» в настройках: переключатель прогнозов, постоянное
  обучение, минимум примеров, порог уверенности, число партий в прогнозе;
- API `api_neural` (`status`, `enable`, `disable`, `train`, `reset`,
  `configure`) и мост `Bridge.neural` в Kotlin;
- статья документации «Нейросеть: обучение и прогнозы» (28 статей);
- выбор видов спорта для прогнозов сети: чипы с галочками рядом с
  переключателем «Прогнозы по нейросети» (настройка `neural.sports`).
  Обучение идёт по всем видам, а прогнозы сеть отдаёт только по отмеченным;
- выбор типов ставок по каждому виду (настройка `neural.markets`): сеть
  прогнозирует только отмеченные рынки — победитель, тотал, фору, «обе забьют»;
- два новых выхода сети для командных видов: **фора** (по текущей линии из
  коэффициентов, Ф1/Ф2) и **обе забьют** (да/нет);
- защита от переобучения:
  - «оставлять лучшую модель»: новая модель принимается, только если её
    точность на отложенной выборке не хуже прежней, иначе в лог пишется
    «переобучение отклонено»;
  - «заморозить обучение»: веса не меняются автоматически (`neural.freeze`);
  - остановка по плато: после 3 раундов без роста точности вид больше не
    дообучается автоматически;
  - резервная копия модели и откат кнопкой «↩︎ откат» (API `rollback`);
- история обучения по видам: точность, база и lift после каждого раунда,
  тренд (растёт / проседает / стабильно) и признак плато — в статусе и в
  карточке на панели (столбики, красный — отклонённое переобучение);
- `tests/test_nn.py`: 98 проверок — признаки, метки, обучение, сбор данных,
  разметка, прогнозы, слияние, выбор видов и рынков, защита от переобучения
  (keep_best, freeze, плато, история, откат), API.

Изменено:

- `predictor_core.py`: признаки считаются один раз на матч и используются и
  для обучения, и для прогноза; разметка завершённых матчей и запуск
  дообучения — в цикле и в потоке проверки результатов;
- `engine_api.py`: статус нейросети в состоянии движка, очистка данных по
  ключу `neural`;
- версия: `APP_VERSION 1.9.0`, `versionCode 10`, `versionName 1.9`.

Проверено: Python-регрессии (14/14), браузерный стенд, живой фид Betcity
(91 матч, разбор признаков по всем видам), сборка и содержимое APK. Не
проверено: обучение и прогнозы на реальном устройстве, скорость обучения на
телефоне.

## 1.8 — 22.10.2026

**Тема:** одновременный анализ всех видов спорта.

Добавлено:

- `get_live_matches()` без аргумента получает один общий live-фид Betcity и
  собирает матчи всех шести видов; явный вид остаётся точечным фильтром для
  теста правил;
- `run_cycle()` обрабатывает все виды за цикл, пишет в сводку `sports` и
  `by_sport`, использует вид каждого матча для статистики, правил конструктора,
  прогноза и отправки;
- `refresh_queue()` отдаёт матчи всех видов с правильным `sport` и
  `sport_name`; заголовок очереди показывает «Все виды», если их несколько;
- авто-правила пересобираются по каждому виду; включение, выключение и смена
  порогов действуют сразу на все виды, ручные правила не затрагиваются;
- настройка `max_matches_per_sport` (по умолчанию 10, 0 — без ограничения) и
  поле «Матчей на вид за цикл»: ограничение нагрузки при разборе всех видов,
  отложенные матчи уходят в следующий цикл и не теряются;
- `tests/test_all_sports.py`: 10 проверок общего фида, сводки и очереди;
- в интерфейсе явно указано: активный вид нужен для правил и каталога, а
  прогнозы идут по всем видам.

Изменено:

- `active_sport` больше не ограничивает линию, статистику, прогнозы, очередь и
  проверку результатов — только интерфейс и выбор правил;
- версия: `APP_VERSION 1.8.0`, `versionCode 9`, `versionName 1.8`.

Проверено: Python-регрессии (13/13), включая новый набор всех видов, и сборка
APK. Не проверено: одновременные прогнозы по нескольким видам на реальном
устройстве и расход батареи при опросе всех видов.
