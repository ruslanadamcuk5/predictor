# TESTING — проверка проекта

## 1. Что проверяется сейчас

На машине разработки нет Android-устройства или эмулятора. Поэтому проверены:

- Python-логика через `tests/`;
- WebView-интерфейс через браузерный стенд;
- сборка, подпись и содержимое APK.

Не проверено: запуск Chaquopy на реальном телефоне, реальная линия в
приложении, системные уведомления, foreground-сервис, переключение видов на
устройстве.

## 2. Окружение

```powershell
$env:PYTHONUTF8="1"
$env:PYTHONIOENCODING="utf-8"
```

Python 3.13. Chaquopy собирает `app.imy` тем же buildPython, который указан в
`app/build.gradle.kts` (`C:/Program Files/Python313/python.exe`). На другой
машине путь нужно поправить.

PowerShell показывает `RequestsDependencyWarning` и завершает команду с кодом
1 даже при успешном тесте. Смотрите итоговую строку теста.

## 4. Фикстуры


## 6. Проверка на устройстве

Требуется arm64 Android 7.0+ (или x86_64 эмулятор).

```powershell
adb install -r ..\Predictor-1.6.apk
adb logcat -c
adb shell am start -n by.betcity.predictor/.MainActivity
adb logcat | Select-String -Pattern "python|chaquopy|betcity|Predictor"
```

Чек-лист:

01. Приложение запускается, статус-бар скрыт.
02. Панель показывает версию 1.6 и активный вид.
03. «Проверить» возвращает Betcity: ok и число матчей.
04. Переключение всех 6 видов не роняет приложение.
05. Очередь показывает линию выбранного вида и счёт в правильном формате.
06. «Запустить»: движок работает, уведомление foreground видно.
07. Конструктор:
    - для каждого вида свой набор метрик и рынков;
    - шаблоны добавляются;
    - правило сохраняется и остаётся после перезапуска;
    - «Тест на линии» не падает.
08. Переключение вида не удаляет правила других видов.
09. Результаты: фильтры по виду, дате, поиску, статусу работают.
10. Статистика: разбивка по видам совпадает с результатами.
11. Анализатор: фильтры скрываются по виду; «В конструктор» предлагает новое
    правило или существующее; условие появляется в редакторе, после сохранения
    правило подсвечивается.
12. Документация: вкладка открывается, 26 статей, поиск и фильтры работают;
    статья «Справочник метрик» подгружает метрики активного вида; текст
    читается, таблицы прокручиваются, нижнее меню из 9 пунктов не переполняется.
13. Логи: уровни, поиск, очистка, экспорт.
14. Настройки: сохранение и сброс.
15. Экспорт: отчёты, CSV, JSON, логи, правила.
16. «Остановить»: сервис и уведомление исчезают.
17. Проверка результата: прогноз закрывается по завершённому матчу, для
    форы push не считается ни победой, ни поражением.
18. Поворот экрана/фон: приложение не теряет состояние критично.
19. Кнопки «?» в конструкторе и анализаторе открывают нужную статью, системная
    кнопка «Назад» возвращает из статьи к списку, а не закрывает приложение.

Результат чек-листа зафиксируйте в `ROADMAP.md`.

```powershell

C:\Android\build-tools\34.0.0\aapt2.exe dump badging ..\Predictor-1.6.apk
```

## 8. Что считается неудачей

- Ошибка импорта Python на устройстве (`ModuleNotFoundError`).
- Пустой каталог метрик или шаблонов для вида.
- Падение при переключении вида.
- Прогноз без снимка статистики (анализатор не увидит данные).
- Ошибка сохранения правил (`ok: false`).
- Чёрный/пустой WebView после запуска.
- Утечка реального `token`/`chat_id` в логи или экспорт.
